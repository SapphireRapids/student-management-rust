## 结论速览（2026-10-02）

- **正确性**：全量 `cargo test` 24/24 通过（13 单元 + 5 api_json + 4 console_race +
  2 save_atomicity）；9 阶段压测真实网络错误 0；`taskkill -9` 强杀后数据文件
  零损坏、重启后接口与文件一致。
- **性能**：500 条种子数据、默认 1 worker，8 客户端混合负载 793 请求/秒、
  p99 延迟 19.2 ms，0 错误；`--threads 2` 在数据量增大后接近翻倍。
  吞吐绝对值低于 v1.4.0 历史报告约 28%，系本机偶发停顿（杀毒/调度），
  见压测报告"吞吐差异说明"。
- **原子性有回归测试背书**：把 `save()` 退回"直写原文件"的旧写法，
  两个原子性测试 7.6 秒内双红。
